# Glancemark Homebrew tap

Install Glancemark on Apple Silicon Macs running macOS 27 or later.

```sh
brew install --cask Kian-hdr/glancemark/glancemark
```

Open Glancemark once so macOS can register the Finder preview. The cask installs the same signed and notarized DMG offered on [GitHub Releases](https://github.com/Kian-hdr/glancemark/releases).
